Admin-Keyboard – Help V%%VERSION%%

Admin-Keyboard is an ESP32-S3 device that acts as a USB HID keyboard and is configured over a Wi-Fi web interface. Connect to it via its Wi-Fi access point (or your local network), open the web UI, and send keystrokes or run macros to the host PC.

Getting started

  1. Power the device. It broadcasts a Wi-Fi access point (default SSID printed on the device or set in Wi-Fi Settings).
  2. Connect your phone or laptop to that AP.
  3. Open http://192.168.4.1 in a browser.
  4. Plug the device into the target PC via the USB-OTG port — the status bar will show USB HID: Enumerated when the PC recognises it as a keyboard.
  5. Type in the text area or run a macro — keystrokes are delivered to whatever is focused on the target PC.

The device can also join your existing Wi-Fi network (see Wi-Fi Settings), making it reachable from anywhere on that network without connecting to the AP.

Send keys

Click in the text area and type. With Send keys immediately checked every keystroke is forwarded in real-time (including Ctrl, Shift, Alt combinations). Uncheck it to compose text first, then click Send as Text to type it all at once.

Use the modifier checkboxes (LCtrl, RCtrl, LShift, RShift, LAlt, RAlt, Super) to hold extra modifiers that are combined with each key you press.

Works on mobile too — the soft keyboard sends text via the input event path.

Lock keys

The NUM / CAPS / SCRL indicators reflect the lock-key state reported by the host. Click them to toggle the corresponding lock key on the host.

Media keys

The media buttons send consumer-control HID reports: Play/Pause, Previous, Next, Mute, Volume Down, Volume Up.

Macros

A macro is a named script stored in flash. Save up to 20 macros. Click Run to execute a macro; it runs in the background so you can continue using the UI.

Macro script language

Each line of a macro body is one command. Blank lines and unknown commands are ignored.

CommandDescriptionExample
STRING <text>Type text character by character.STRING hello world
KEY <name>Press and release one key (no modifier).KEY ENTER
COMBO <mod>+…+<key>Hold modifiers and press a key simultaneously.COMBO LCTRL+C
MEDIA <name>Send a consumer-control (media) key.MEDIA PLAY_PAUSE
DELAY <ms>Wait ms milliseconds (max 30000).DELAY 500

Wi-Fi settings

Access Point (AP)

The device always runs its own AP so you can reach it even without an external network. Change the AP SSID and password in Wi-Fi Settings → Access Point. Leave the password field empty for an open (no-password) network. Changes take effect after restart.

Station (STA) — joining an existing network

Use Scan for Networks to find nearby APs, select one, enter its password, and click Save & Connect. The device will connect and show its IP in the status bar. Multiple networks can be saved; the device connects to the strongest known one automatically on boot.

Saved networks are listed under Saved Networks. You can manually connect to or delete any entry there.
